# Fantasy Calendar

**Create calendars for worlds where ordinary time doesn't apply.**

Fantasy Calendar is a desktop calendar application for fictional worlds, tabletop role-playing games (TRPGs), worldbuilding, and storytelling. Design your own calendar system, organize events, and track timelines without being limited to the real-world Gregorian calendar.

Whether your world has ten days in a week, thirteen months in a year, or a completely different set of holidays, Fantasy Calendar lets you build a calendar around your setting.

## Features

### Custom calendar systems

* Define the **number of months in a year**.
* Set the **number of days in each month**, allowing months of different lengths.
* Customize **month names** and **weekday names**.
* Choose the **number of days in a week**.
* Designate recurring **weekly holidays or rest days**, such as the equivalent of Saturday and Sunday.
* Reorder or remove months and weekdays as needed.

### Event management

* Create events for specific dates on your custom calendar.
* Set event **durations**, including multi-day events.
* Schedule **recurring events** on weekly, monthly, or yearly cycles.
* Add notes and descriptions to events.
* View events associated with a selected date.

### Multiple calendars

* Create and manage multiple independent calendars.
* Give each calendar its own **name, description, and banner image**.
* Switch between calendars for different worlds, campaigns, or projects.

### Calendar navigation and appearance

* Browse previous and following years or jump directly to a specified year.
* View custom month and weekday names in the calendar.
* Change the application's theme and language in Settings.

## Use Cases

* **Worldbuilding:** Create original timekeeping systems for fictional civilizations.
* **Tabletop RPGs:** Track quests, adventures, character birthdays, and campaign events.
* **Creative writing:** Organize historical timelines, festivals, and significant events in fictional settings.
* **Game development:** Plan in-game seasons, holidays, and narrative events using custom calendars.

## Getting Started

1. Download the available application build from the [Fantasy Calendar ]().
2. Launch `Fantasy Calendar.exe`.
3. Create a calendar and enter its name, description, and optional banner image.
4. Configure months, weekdays, and weekly holidays.
5. Open your calendar and start adding events.

> \*\*Note:\*\* The linked demo documentation describes version `0.0.1` and a Windows executable. Availability and behavior may differ in later releases.

## How to Use

### Create a calendar

Select the **+** button to create a new calendar. Enter a name, optionally add a description and banner image, and save it. The demo documentation recommends a banner image size of **900 × 200 px**.

### Configure months and weekdays

In the advanced calendar settings:

* Add months, assigning each a name and a number of days.
* Arrange months in the order used by your fictional world.
* Add and name weekdays to determine the length of a week.
* Mark individual weekdays as regular holidays or rest days.

### Browse dates

Open a calendar from the calendar list. Navigate between years using the year controls, or enter a year directly. Select a date to view its events.

### Add events

Select the **+** button in the event interface, enter the event details and duration, and optionally configure a weekly, monthly, or yearly recurrence. Use event notes to record additional information.
